# Creative Concept Point CV Maker (ক্রিয়েটিভ কনসেপ্ট পয়েন্ট সিভি মেকার)

একটি আধুনিক, দ্রুত এবং পেশাদার দ্বিভাষিক (বাংলা ও ইংরেজি) সিভি এবং বৈবাহিক বায়োডাটা তৈরির ওয়েব অ্যাপ্লিকেশন।

---

## ✨ বৈশিষ্ট্যসমূহ (Features)

1. **দ্বিভাষিক সমর্থন (Bilingual):** সম্পূর্ণ ইন্টারফেস ও সিভি বাংলা এবং ইংরেজি উভয় ভাষায় তৈরি ও ডাউনলোড করা যায়।
2. **সিভি এবং বায়োডাটা মোড (Dual Mode):**
   - সাধারণ প্রফেশনাল জব সিভি (Job Resume)
   - পাত্র/পাত্রীর পারিবারিক ও বৈবাহিক বায়োডাটা (Matrimonial Biodata)
3. **আধুনিক থিমসমূহ (Themes):**
   - Elegant Executive (Navy & Gold)
   - Modern Emerald (Green & Slate)
   - Royal Burgundy (Burgundy & Rose)
   - Creative Indigo (Indigo & Violet)
   - Minimalist Monochrome (Classic Black & White)
4. **স্মার্ট ফটো ক্রপ ও সাইজিং:**
   - ড্র্যাগ অ্যান্ড ড্রপ ও স্লাইডার দিয়ে ছবি জুম এবং কাস্টম ক্রপ।
5. **কাস্টম সেকশন ও অতিরিক্ত ফিল্ড:**
   - নিজের পছন্দমতো যেকোনো শিরোনাম বা অতিরিক্ত তথ্য যোগ করার সুবিধা।
6. **AI অ্যাসিস্ট্যান্ট (Gemini Integration):**
   - জব টাইটেল অনুযায়ী অটোমেটিক সামারি ও স্কিল সাজেশন জেনারেট করার সুবিধা।
7. **১-ক্লিক হাই-কোয়ালিটি PDF এক্সপোর্ট:**
   - সরাসরি ব্রাউজার থেকে ক্রিস্প এবং প্রিন্ট-রেডি PDF ফাইল ডাউনলোড।
8. **অটো-সেভ (Auto-save):**
   - ব্রাউজারের লোকাল স্টোরেজে তথ্য সংরক্ষিত থাকে, পেজ রিলোড দিলেও ডাটা হারায় না।

## 🚀 গিটহাবে পুশ করার কমান্ড (Push to GitHub)

আপনার কম্পিউটারের টার্মিনাল বা কমান্ড প্রম্পটে (প্রজেক্ট ফোল্ডারে থাকা অবস্থায়) নিচের কমান্ডগুলো চালান:

```bash
git init
git add .
git commit -m "Initial commit for Creative Concept Point CV Maker"
git branch -M main
git remote add origin https://github.com/minhajulabedin2000/cvmaker-by-ccp.git
git push -u origin main
```

## 🌐 লোকাল সেটআপ (Local Setup)

```bash
# ডিপেন্ডেন্সি ইন্সটল করুন
npm install

# ডেভেলপমেন্ট সার্ভার চালু করুন
npm run dev
```

ব্রাউজারে দেখুন: `http://localhost:3000`

---

## 🚀 ভার্সেল ডিপ্লয়মেন্ট (Deploy to Vercel)

1. [Vercel](https://vercel.com) এ লগইন করে **Add New Project** এ যান।
2. `cvmaker-by-ccp` রিপোজিটরিটি ইমপোর্ট করুন।
3. বিল্ড সেটিংস:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. **Deploy** বাটনে ক্লিক করুন।
